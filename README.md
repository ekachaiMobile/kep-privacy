# Kep — Privacy Policy

The published privacy policy for the Kep iOS app, in Thai and English.

Live at <https://ekachaimobile.github.io/kep-privacy/>, which is the URL given to
App Store Connect.

The same text is kept in the app itself (Settings → ความเป็นส่วนตัว) so it can be
read offline, and in `PRIVACY.md` in the app repository. Update all three together.
